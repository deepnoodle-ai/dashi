# 13. Child turns and delegation — comparative research

**Status:** research, 2026-09-28. **Question:** What must Dashi record when a parent Turn delegates a tool call to another agent? A child Turn is a separate execution with its own record; a workflow that merely runs agents in parallel is not necessarily a child-Turn contract.

## Dashi baseline

The [roadmap](../remaining-work.md) calls this an L/high-difficulty gap. Dashi defines a subagent as an agent performing a child Turn (`design/ubiquitous-language.md:29-40`), but `StartFact`, `Start`, and `TurnView` have no parent coordinate (`turn.go:248-258,427-439`; `state.go:54-95`). A caller can start another `Runner` inside a tool. The caller can assign and save its Turn ID before execution for crash recovery (`turn.go:130-141`); `Recorder`/`Loader` persist and reload one Turn (`recorder.go:60-83`). A tool may return a detached handle and later be settled (`tool/tool.go:323-328`; `turn.go:464-476`). Those pieces do not yet say which child belongs to which parent call, who cancels it, or how to resume the parent after it finishes.

`Budget` caps one Turn's model calls (`budget.go:22-31`); `TurnView.Spend` reconstructs that Turn's model and tool facts (`state.go:67-72`). `Spend.ToolCost` is outside `MaxCost` (`budget.go:164-185`). The budget design leaves child roll-up open (`design/budgets.md:229-235`). Thus simply reporting a child as tool cost would lose its token accounting and imply the wrong limit semantics.

## Lessons and tradeoffs

1. **Record causality at admission.** Nvoken's immutable `(parent Turn ID, parent tool call ID)` is a small, useful coordinate. A stable caller-assigned child ID also lets a retried tool call find the same child. Canvas shows why deduplication after launch is too late for billable work.
2. **Keep execution and presentation distinct.** Mobius and Pi make progress and cost visible while a child runs. Eino demonstrates that streamed inner events may be display-only, absent from the parent's durable record. Dashi should link to the child's own recorded facts instead of copying its private transcript into the parent.
3. **Say what cancellation means.** A blocking child can inherit `context.Context`; background work needs an explicit durable cancel/reconcile path. Dive's optional in-memory registry is useful locally but cannot prove cancellation after restart.
4. **Avoid false budget promises.** OpenHands rolls up cumulative child metrics; Mobius counts in-flight child cost; Nvoken provides attribution without inheritance. Dashi can expose exact per-child and inclusive spend, but an aggregate spending cap across independent Turns requires host admission/reservation or a new shared budget authority. `Budget` alone cannot enforce it.

## Evidence notes

This was source inspection at the commits above, not a live or paid run. Nvoken's checkout had unrelated uncommitted changes; the cited `TurnTrigger` and public-read paths were checked against `HEAD`. “No child-Turn contract” describes the cited APIs and targeted searches, not every extension or downstream application. No source supports assuming child permissions, tools, memory, or history should inherit automatically.
