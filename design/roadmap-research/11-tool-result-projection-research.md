# 11 — Tool-result size and projection: research

**Status:** research snapshot, 2026-09-28. **Roadmap:** [item 11](../remaining-work.md), M / high difficulty. **Question:** what happens when a tool returns more material than the next model request can carry, and can a developer still inspect what the tool actually returned? This is about local/external tool results. Provider-hosted tool results also need size accounting, but Dashi cannot edit their provider-private replay without losing fidelity.

## Dashi baseline

`tool.Output` has ordered `Content` (the model-facing blocks) and optional `Display` for presentation (`tool/tool.go:219-241`). A completed `tool.Outcome` validates block shape but has no size bound (`tool/tool.go:340-385`). Local and externally settled results enter `StepToolSettled` with the outcome (`runner.go:560-575`; `state.go:700-725`). `Project` clones that output into a `ToolResult` message without reducing it (`project.go:129-164`); the next `Prepare` sees it. The full result is thus in the Turn record **and** repeated in model-facing history. `Display` is not a smaller model view. A large result can inflate the record and exceed a later provider context limit. No approved Dashi result-size design exists; [adjacent-library findings](../gaps/C-adjacent-libraries.md) and [design pitfalls](../design-pitfalls.md) call for a recorded projection adjustment that keeps the fact intact.

## Lessons and tradeoffs

1. **Limit before the next model call, but after recording what happened.** Mobius proves one result can poison the next call and subsequent session. Its hook mutates the canonical result, while Dashi can retain the original `StepToolSettled` fact and record a separate model view in that settlement. A callback that simply overwrites output loses the audit trail.
2. **Say what is missing and how to recover it.** pi's offset instructions and Mobius's fetch handle make clipping usable. A naked ellipsis can make the model answer from incomplete evidence. Any reference must have ownership, lifetime, digest and an authorized read path; Dashi should not promise `fetch` unless the host supplies it.
3. **Keep boundaries explicit.** Byte caps protect request size but do not guarantee fit within a model's token window. Multimodal blocks, structured results, provider-private hosted activity and later session compaction need distinct policies. Canvas's UI truncation is only presentation. Tool error/success state should not change merely because the model saw an abbreviated result.
