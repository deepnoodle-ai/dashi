# Context compaction: comparative research

**Roadmap item 15.** Source inspection on 2026-09-28; revisions pin the local checkouts. “Implemented” means the inspected source has a usable path, not that every production deployment enables it. No live provider test was run.

## Dashi baseline

Dashi has no compaction or overflow-recovery policy (`design/remaining-work.md:144-150`). Its turn does not own prior history: `Start.History` and `Continue.History` come from the caller, and the start fact records a fingerprint (`turn.go:430-459`; `design/decisions.md:125-139`). `Continue` can reject a changed history before committing (`runner.go:403-415`). The runner builds each model request with `projectWithHistory` (`runner.go:958-965,1032-1045`). `ContextItem.Snapshot` replaces a named item **inside one turn's projection**, not old conversation turns (`turn.go:116-128`; `design/runtime-reminders.md:10-21`). Providers classify `ReasonContextWindowExceeded`, but Dashi does not shorten history or retry automatically (`llm/llm.go:638-649`). The separate tool-result projection item addresses one oversized result, not session history (`design/roadmap-research/11-tool-result-projection-prd.md:7-13`). Session ownership remains open even though caller-owned history is settled (`design/remaining-work.md:137-150`).

## Lessons and limits

1. **The record and the model view must differ.** Nvoken, Mobius, pi, ADK, and OpenHands keep raw events/messages and append a coverage record; the model sees summary plus tail. A plain replacement of `[]llm.Message` loses why content disappeared and cannot be audited.
2. **Coverage must name exactly what was summarized.** Sequence/entry IDs are clearer than broad timestamps. ADK's exclusion list exists because a time range can swallow branch/scope holes (`session/session.go:346-371`). Dashi should not infer coverage from summary prose.
3. **Never split a tool exchange.** pi's cut-point rule, Dive's pre-iteration boundary, and MAF's atomic groups preserve provider-valid call/result structure. Recent signed/opaque provider content also needs exact replay, so a first slice should cut only at settled turn boundaries.
4. **Summary generation is another paid model call.** Record model, policy version, usage/cost, failure and whether a summary actually reduced context. A summarizer can itself overflow; a bounded input plan and visible failure path matter. Host UI should show started versus applied, as Mobius and Canvas do.
5. **Dashi's ownership decision is decisive.** `design/history-storage.md:116-153` sketches an immutable host log with a summary entry and fingerprint, but the repository has not accepted a Session API. The smallest viable work before that decision is a contract/projection design, not another runner hook that silently edits caller-owned history.

**Evidence limits:** Comparative snapshot notes in `tmp/research/comparison/` were orientation; claims above were checked in the pinned local source. Nvoken's working tree has unrelated modifications; cited compaction files were clean relative to `deea133a`. Provider behavior and production enablement were not exercised live.
