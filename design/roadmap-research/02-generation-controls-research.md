# Generation controls and provider options — research

Status: source survey, 2026-09-28. Roadmap item [2](../remaining-work.md). “Implemented” below means a route accepts and sends at least one relevant control; it does **not** imply every named control works on every model. Source locations are relative to each checkout. The comparison notes in `tmp/research/comparison/` oriented this survey; claims below were checked in code. No live provider calls were made.

## Dashi baseline

`llm.Settings` has `MaxTokens`, `Temperature`, `Reasoning`, `ToolChoice`, `ParallelTools`, and `Citations`, but no stop sequence, `top_p`, seed, or requested service tier (`llm/llm.go:358-393`). `llm.Input.Validate` checks explicit temperature and reasoning (`llm/llm.go:420-440`). Capability fitting can clamp or omit a known incompatible temperature and emits a recorded adjustment and warning (`llm/fit.go:91-135`; [model controls](../model-controls.md)). `RequestSnapshot` stores original input, effective settings, adjustments, evidence, and exact encoded body (`llm/request.go:13-52`). `Result.ServiceTier` is **reported** tier, not a request control (`llm/llm.go:531-534`). New controls must extend this one preparation path and its capability evidence; simply encoding new fields would leave the request record misleading.

## Lessons for Dashi

1. **Make the common path obvious.** A caller should find stop sequences and nucleus sampling next to temperature, with unset distinct from explicit zero. Eino's common options and Nvoken's small `sampling` concept help; ADK-Go's vendor-shaped shared config does not.
2. **Never equate accepted with applied.** Dive's ignore rule, Pi's route-limited map, and OpenHands SDK's filtering can surprise callers. Dashi can improve on all three by validating at `Prepare`, showing requested/effective values, and warning for any safe omission.
3. **Keep vendor controls typed and scoped.** Seed and service tier have route-specific support and semantics. Microsoft shows the value of native types; Pi shows the cost of unbounded raw JSON that can override named fields. A small provider-owned typed option can preserve discoverability without making `llm.Settings` a union of every vendor API.
4. **Do not promise determinism.** A seed is a request hint, not proof of repeatable output. Service tier affects price and must be retained per attempt alongside reported tier. Prompt-cache controls are [roadmap item 3](../remaining-work.md), and need their own design.
