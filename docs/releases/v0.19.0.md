## Highlights

A `BeforeModel` hook that hides tools can now choose what the model hears
when it calls one of them anyway. Set `ModelDecision.HiddenReply`, and a call
to a tool that hook hid gets that text as its result instead of "This tool is
not available now." The tool does not run.

This matters for hosts that defer large tool sets and load tools on demand.
Instructions often name a tool before it is loaded, and the default reply
reads as a dead end. A reply such as "Search for it with find_tools, then
call it." saves the model a wasted step.

The reply applies only to the tools its own hook hid; a tool hidden by another
hook keeps the default answer. Replies are recorded in
`ModelFact.HiddenReplies`, so a turn resumed after a crash answers the same
way, and older records keep the default. A reply is limited to 4 KiB. The
change is additive: no code needs to change.

Upgrade with `brew upgrade deepnoodle-ai/tap/dashi`.

## Changelog

### Added

- `ModelDecision.HiddenReply`: the tool result a call to a tool this hook
  hid gets, in place of "This tool is not available now." It applies only to
  the names that hook hid, is recorded in the new `ModelFact.HiddenReplies`,
  and is at most 4 KiB. Use it to tell the model how to load a deferred tool.
