## Highlights

The `dashi` CLI can now be installed directly with
`go install github.com/deepnoodle-ai/dashi/cmd/dashi@latest`. While the
repository is private, set `GOPRIVATE=github.com/deepnoodle-ai/*`. The library
API is unchanged from v0.1.0.

Contributors: the repository now uses a committed `go.work` instead of
`replace` directives, so in-repo builds keep using the local modules. Releases
are cut with the `make` targets described in `docs/dev/releasing.md`.

## Changelog

### Changed

- **Installable CLI.** `go install github.com/deepnoodle-ai/dashi/cmd/dashi@latest`
  now works. A committed `go.work` replaces the sub-modules' `replace`
  directives, which `go install` refuses. (#163)
- **Release tooling.** `make release-prep`, `release-notes`, `tag-modules` and
  `release-publish` cut a release of all four modules together. (#162)
