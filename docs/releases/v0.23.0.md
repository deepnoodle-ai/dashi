## Highlights

This release adds Google's Gemini 4 Neon (`gemini-4-neon`) to the model
catalog, checked with live calls and priced for cost estimates and budget
limits. It supports `low` through `xhigh` reasoning effort (default `high`),
marks temperature unsupported, and uses a unified 1M-token window with a
65,536-token synchronous output limit.

The `dashi` CLI now features `gemini-4-neon` for Google in place of
`gemini-4-argon`, matching Google's Carbon, Neon, Hydrogen, and Flash-Lite
lineup. Provider defaults are unchanged (`gemini-4-hydrogen` stays Google's
default), and there are no breaking API changes. Upgrade with
`brew upgrade deepnoodle-ai/tap/dashi`.
