## Highlights

Applications can now send microphone audio while a model speaks through
the new `realtime` API. Gemini Live (`providers/google/geminilive`) and Grok
Voice (`providers/grok/voice`) share commands and events for audio,
transcripts, interruptions, tool calls, completion, and available usage.

Use `Client.Connect` to open a session, then `Send` and `Receive` to exchange
commands and events. Applications own devices, playback, tool execution,
and session lifetime. See `realtime/example_test.go` for an executable
example using a fake connection.

Transport bounds and provider wire tests cover cancellation, interruption,
and tool ownership. No live or paid provider requests ran for this release.
Model availability, voice quality, and account access need live qualification.
Playback truncation, reconnection, and history resumption remain unsupported.

### Added

- **`realtime` supports bidirectional voice sessions** through Gemini Live
  (`providers/google/geminilive`) and Grok Voice (`providers/grok/voice`).
  Sessions expose audio, transcripts, interruptions, tool calls, completion,
