## Highlights

This patch release moves Dashi to Wonton v0.8.1, which fixes three small
terminal UI bugs found by a second audit of Wonton's v0.8.0 fixes. In the
Dashi CLI, a wide dash in a reply no longer leaves earlier text showing
through. The library API and recorded formats are unchanged from v0.12.0, so
upgrading needs no other changes.

## Changelog

### Fixed

- **The CLI picks up Wonton v0.8.1's terminal fixes.** A width-3 or width-4
  dash (`⸺`, `⸻`) in a reply now clears the columns it covers, so text drawn
  there before no longer shows through. Wonton's input focus and prompt
  autocomplete fixes come with it.
