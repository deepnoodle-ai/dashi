## Highlights

Dashi v0.14.0 finishes the CLI's visual redesign. The library API is
unchanged.

The CLI now works on light terminals. At startup the screen asks the terminal
for its background color and, on a light background, switches text, the
prompt band, code panels, and syntax colors to a light palette. If the
terminal does not answer within 300ms, dashi uses the dark palette. Pick one
yourself with `--theme dark` or `--theme light`, or set `DASHI_THEME`; that
also skips the question, which helps over slow SSH connections.

Dialogs now share the prompt's band. Approvals, questions, and pickers take
the composer's place on its gray background, their titles start with a
yellow `?` when Dashi needs an answer or a blue `◆` for a choice you opened,
and approval keys read `y Allow once`.

Upgrade with `brew upgrade deepnoodle-ai/tap/dashi`.

## Changelog

### Added

- **The CLI detects light terminals and uses a light palette.** At startup
  the screen asks the terminal for its background color; on a light
  background, text, the prompt band, code, and syntax colors switch to light
  values. `--theme dark|light` or `DASHI_THEME` overrides the detection.

### Changed

- **Dialogs draw on the prompt's band.** Approvals, questions, pickers, the
  session picker, the MCP startup review, and the inspector that opens over
  a pending dialog take the composer's place and its gray background,
  instead of starting with a rule. Each title starts with a glyph in its
  role color: a yellow `?` when Dashi needs an answer, a blue `◆` for a
  choice you opened. The title itself is plain bold. The selected row has
  a blue `❯` and a bold label, and approval keys read `y Allow once` with
  the letter in blue and no brackets. Key hints sit below the band.
