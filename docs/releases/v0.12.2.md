## Highlights

The `dashi` CLI can now be installed with Homebrew:
`brew install deepnoodle-ai/tap/dashi`. Each release attaches `dashi`
binaries for macOS, Linux, and Windows, built and published by a release
workflow, and `dashi --version` reports the release in those builds.

The library is unchanged from v0.12.1, so upgrading needs no other changes.
