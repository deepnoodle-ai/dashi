## Highlights

A plain `Continue` after a reply hits its `max_tokens` limit now works on
every model. Before, it sent the cut-off reply as an assistant prefill, which
current Claude models and Anthropic models with reasoning on reject, so the
turn failed. The continued call now ends with a short runtime reminder to pick
up where the reply stopped. Later turns' history does not include it.

`delegate.Tasks.Watch` is new: it yields one task's recorded child Turns, then
its live events, each step once and in order. Any client that shows a task
live can use it instead of merging the record and live events itself. The
`dashi` CLI's task panes now do.

Two changes may need action. `gemini.New` with `Vertex` and no `Client` now
rejects a custom `Endpoint` that is not `https` on a Vertex AI host, so a
mistyped endpoint no longer receives your ADC token; supply a `Client` to use
another host. The `dashi` CLI moves to Wonton v0.14.0, so usage errors exit 2
instead of 1; update scripts that check for 1.

Upgrade with `brew upgrade deepnoodle-ai/tap/dashi`.

## Changelog

### Added

- `delegate.Tasks.Watch(ctx, id)` yields a task's recorded child Turns, then
  `TaskUpdateRecordEnd`, then its live events, each step once and in order,
  reloading missing steps from the record. The `dashi` CLI's task panes use it.

### Security

- `gemini.New` with `Vertex` and no `Client` rejects a custom `Endpoint` that
  is not `https` on a Vertex AI host, instead of sending it Dashi's ADC token.
  Supply a `Client` to use another host.

### Changed

- `dashi` CLI: built on Wonton v0.14.0. Usage errors exit 2 instead of 1, and
  flags that take a name or text, such as `--model`, reject a value that looks
  like a flag (`dashi --model --plain` is now a usage error).

### Fixed

- A plain `Continue` after a `max_tokens` stop no longer fails on models that
  reject an assistant prefill: the continued call ends with a short runtime
  reminder, which later turns' history does not include.
- `delegate`: a child whose first commit has an unknown outcome but landed is
  reported as a failed run, not as never started, and `Recover` resumes it.
