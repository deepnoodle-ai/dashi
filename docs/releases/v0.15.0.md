## Highlights

Dashi v0.15.0 makes the CLI quieter. The library API is unchanged.

Tool calls now read as short phrases instead of raw arguments and output:
`Reading render.go…` while a call runs, `Read render.go` when it is done,
`Searched for “foo”`, `Ran a command`. A row shows only that phrase and its
time. Click a row in fullscreen to see the call's full input and output, and
click its first line to hide them again; in inline mode, `/scrollback` shows
them. Approvals and decide checks stay visible, and
`--plain` output is unchanged. Replies use the full terminal width again, and
an empty row always separates the transcript from the UI below it.

The `/model` picker lists only current models from destinations you have a
key for, with a short context size on each row; *All models…* opens the rest.
To choose the picker's models yourself, set `featured_models` in
`~/.dashi/settings.json`, such as
`{"anthropic": ["claude-opus-5-5"], "openai": ["gpt-6-luna"]}`.

Upgrade with `brew upgrade deepnoodle-ai/tap/dashi`.

## Changelog

### Changed

- **Tool rows say what a call does and hide its input and output.** Each
  row reads as a short phrase, such as `Reading render.go…` while the call
  runs and `Read render.go` when it is done, `Searched for “foo”`, or
  `Ran a command`. MCP tools read as `Create issue · github`. The row no
  longer shows the raw argument, the `└` result line, live command output,
  or `click to expand`; a failed call shows only `failed`. Click a row in
  fullscreen to show the call's input and whole output, and click its first
  line again to hide them. Inline mode prints rows collapsed, and
  `/scrollback` shows every call expanded. Decide checks and approvals stay
  visible. `--plain` output is unchanged.
- **Replies and tool rows use the whole terminal width again.** The
  100-column reading width is gone.
- **One empty row always separates the transcript from what is under it**:
  the working line, hints, the prompt, and dialogs such as approvals,
  questions, and pickers.
- **The `/model` picker lists current models you can use.** Each built-in
  destination offers a short list of its newest models, without dated
  snapshots, duplicate aliases, or older generations, and only destinations
  with a credential appear. One muted line names the keys that would add
  the others. Each row shows the context window and marks the current
  model; the panel of tool and evidence details is gone. A last row, *All
  models…*, opens the complete list. Destinations from user settings still
  list every model, `/model <name>` still accepts any registered model, and
  `dashi models` is unchanged. To choose the picker's models yourself, set
  `featured_models` in `~/.dashi/settings.json`, such as
  `{"anthropic": ["claude-opus-5-5"], "openai": ["gpt-6-luna"]}`; it
  replaces the built-in lists.
