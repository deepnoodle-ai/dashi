## Highlights

Subagents and CLI turns get more room. The `delegate.Explore` and
`delegate.General` subagents now allow 100 model calls, up from 24 and 32, and
a `dashi` CLI turn allows 100, up from 40. Long research and multi-step tasks
no longer stop early for a manual raise. Monetary caps do not change.

Saved turns keep the limit they were recorded with. Raise an older child with
`/continue`. The library default of 8 for an agent with zero
`Limits.ModelCalls` is unchanged.

Upgrade with `brew upgrade deepnoodle-ai/tap/dashi`.
