## Highlights

Veo video jobs now run on Vertex AI. `gemini.NewVertexVideoJobs` submits
and polls Veo 3.1 jobs (`veo-3.1-generate-001`, `veo-3.1-fast-generate-001`,
and the preview `veo-3.1-lite-generate-001`) with your Google Cloud project's
Application Default Credentials, with no Gemini API key. Google retired the
Veo 3.1 preview models from the Gemini API on 2026-10-22, so Vertex is now
the route for Veo. Image generation stays on `gemini.NewMedia`.

Each video result now carries `VideoUsage`: the length, frame size,
resolution tier, and whether the file has an audio track, read from the MP4
that came back rather than from the request. Hosts that bill per second by
resolution and audio can price from it directly.

Audio is on by default. Set `media.VideoSettings.DisableAudio` for a silent
video. This replaces Grok's `imagine.VideoOptions.GenerateAudio`, which is
removed: Grok callers that set it to false should set `DisableAudio` instead.

## Changelog

### Added

- `gemini.NewVertexVideoJobs` runs Veo video jobs on Vertex AI with the
  project's Application Default Credentials and no API key. It covers
  `veo-3.1-generate-001`, `veo-3.1-fast-generate-001`, and
  `veo-3.1-lite-generate-001`, defaults to `us-central1` (a `global`
  location becomes `us-central1`, recorded as an adjustment on the prepared
  request), and returns the video bytes from the finished job. Without a
  supplied `Client`, it sends its ADC token only to Vertex AI hosts.
- `media.Result.VideoUsage` reports, per video, the length, frame size,
  resolution tier, and audio track measured from the MP4, for billing. It
  describes the file as produced; compare it with the request when billing
  policy needs it.
- `media.VideoSettings.DisableAudio` asks for a video without audio. Vertex
  Veo sends `generateAudio: false` and Grok sends `generate_audio: false`; the
  Gemini API Veo route, Vertex Veo 2 models, and the Interactions video
  clients reject it.

### Changed (breaking)

- Grok's `imagine.VideoOptions.GenerateAudio` is removed. Set
  `media.VideoSettings.DisableAudio` instead.
