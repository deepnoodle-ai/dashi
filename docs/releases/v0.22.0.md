## Highlights

This release adds OpenAI's GPT-6.2 Astra and Sol to the catalog, checked with
live calls and priced for cost estimates and budget limits. Gemini models now
accept a reasoning effort, sent as Google's `thinkingLevel`. An effort a model
does not list moves to the nearest level it does, with a warning.

Image and video support is brought up to date: GPT Image 2.6, Imagine Video
1.5 Lite, Nano Banana 2.1, and Gemini Omni 1.2, which now takes first and last
frames, reference images and videos, edits, and extensions. Models the
providers have shut down, such as `gpt-image-1`, Imagen, and Veo on the Gemini
API, now fail before any request with an error that names a replacement.

Two breaking changes affect media callers. `media.VideoInput.ReferenceFrames`
is now `FirstFrame`, a single image, and Grok's source video, last frame, and
reference images moved from its `VideoOptions` to the shared `VideoInput`
fields. Rename those fields when you upgrade.

The catalog removes `gpt-4.1-nano`, `o3-mini`, and `o4-mini`, which OpenAI has
shut down, and marks nine more OpenAI models and Gemini 2.5 Pro and Flash as
deprecated, with their shutdown dates. Provider defaults are unchanged.
Upgrade with `brew upgrade deepnoodle-ai/tap/dashi`.

## Changelog

### Added

- **`gpt-6.2-astra` and `gpt-6.2-sol` in the model catalog,** with `low` to
  `max` effort. The API now drops reasoning items when earlier history changes.
- **Reasoning effort on Gemini,** sent as `thinkingLevel` for models with a
  documented ladder. Unlisted levels adjust to the nearest one with a warning.
- **GPT Image 2.6 Sunburst and Flare,** with GIF output and `Complexity`
  (`openai/images`).
- **`grok-imagine-video-1.5-lite` and Imagine Image 1.0 limits,** plus 21:9
  and 5:2 video, and up to 14 reference images on Imagine Video 1.5.
- **`gemini-nano-banana-2.1` image limits and Omni durations** of 3 to 15
  seconds.
- **Gemini Omni 1.2 first and last frames, reference images and videos,
  edit, and extension,** through new `media.VideoInput` fields
  `SourceVideo`, `LastFrame`, `ReferenceImages`, and `ReferenceVideos`.

### Changed

- **`media.VideoInput.ReferenceFrames` is now `FirstFrame`,** a single
  image. Grok's `VideoOptions` source video, last frame, and reference
  images moved to `VideoInput`.
- **Retired media models are rejected before any request:** `gpt-image-1`,
  Imagen (the error names `gemini-nano-banana-2.1`), Veo on the Gemini API,
  and Vertex Veo 2 and 3.0. Retired Grok image models send with a warning.
- **Gemini image errors name the finish reason,** such as
  `IMAGE_RECITATION`, when no image comes back.
- **`gemini-2.5-pro` and `gemini-2.5-flash` are marked deprecated.** Google
  deprecated them on 2026-11-02 and, from 2026-12-01, routes their requests
  to `gemini-3.8-flash` and `gemini-3.5-flash-lite`.
- **The CLI features `gpt-6.2-astra` and `gpt-6.2-sol`** for OpenAI, in
  place of `gpt-6-astra` and `gpt-6.1-sol`.
- **Dependencies updated,** notably the Google GenAI SDK to v1.77.0 and the
  MCP Go SDK to v1.8.0.
- **Nine OpenAI models are marked deprecated:** `gpt-5`, `gpt-5-mini`,
  `gpt-5-nano`, `gpt-5-pro`, `o3`, and `o3-pro` shut down 2026-12-11;
  `gpt-4o`, `gpt-4.1`, and `gpt-4.1-mini` shut down 2027-01-14.

### Removed

- **`gpt-4.1-nano`, `o3-mini`, and `o4-mini` leave the model catalog.**
  OpenAI shut them down on 2026-10-23.
