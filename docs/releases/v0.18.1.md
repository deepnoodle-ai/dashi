## Highlights

This is the first published release with Vertex AI Veo support. The
v0.18.0 tags exist, but their release workflow stopped on a flaky test, so
no GitHub release or Homebrew update came from them. Read the
[v0.18.0 notes](https://github.com/deepnoodle-ai/dashi/blob/main/docs/releases/v0.18.0.md) for the Vertex changes: `gemini.NewVertexVideoJobs`,
`media.Result.VideoUsage` for per-second billing, and
`media.VideoSettings.DisableAudio`, which replaces Grok's removed
`imagine.VideoOptions.GenerateAudio`.

This release also fixes a race in `delegate`. When a child task failed before
it was saved, the host sometimes got a `TaskEnded` event, and a session
notice, for a task that was never recorded, after the model had already been
told the call failed. The `task` call's error is now the only report.

Upgrade with `brew upgrade deepnoodle-ai/tap/dashi`.

## Changelog

This is the first published release with the 0.18.0 changes. 0.18.0 was
tagged but never published, so 0.18.1 includes everything listed under it.

### Changed (breaking)

- Grok's `imagine.VideoOptions.GenerateAudio` is removed (from 0.18.0). Set
  `media.VideoSettings.DisableAudio` instead.

### Fixed

- `delegate`: a child that fails before its record holds it no longer
  sometimes also reports a `TaskEnded` event (and a notice to
  `Config.Session`). The `task` call's error is the only report, every time.
