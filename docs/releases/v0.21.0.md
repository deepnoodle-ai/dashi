## Highlights

This release refreshes the model catalog. It adds Claude Fable 5.2, GPT-6.1
Terra, Gemini 4 Carbon and Hydrogen, Meta's Muse Ember, and GLM 5.3, GLM 5.3
Flash, and DeepSeek V4.1 Flash on Mistral. Each was checked with live calls,
and each has prices, so cost estimates and budget limits cover it. Mistral
Large 4 is now generally available, with its larger context window and lower
prices.

Two provider defaults change, which affects any agent that names no model.
Google's default is now `gemini-4-hydrogen`, which Google recommends over
`gemini-3.8-flash`; it costs twice as much per input and output token as 3.8 Flash until
3.8 Flash's price rises on 2027-01-01. Mistral's default is now
`mistral-large-4`, because `mistral-medium-latest` points to a deprecated
model. Name a model on your agent to keep the old behavior.

Meta calls get a cost estimate again. Meta started reporting a different
service tier, so the catalog had no price for any Muse model call.
`catalog.Small("meta")` now returns `muse-ember-1.0`.

Upgrade with `brew upgrade deepnoodle-ai/tap/dashi`.

## Changelog

### Added

- **`gemini-4-carbon` and `gemini-4-hydrogen` in the model catalog,** both
  stable, with a 1,048,576-token context window and a 65,536-token output
  limit for synchronous calls. Carbon costs $2 input, $10 output, and $0.10
  cache read per MTok, doubling on 2026-12-01 as Argon does; Hydrogen costs
  $1.50, $7.50, and $0.075. Both bill $14 per 1,000 search requests and mark
  temperature unsupported, since Google ignores it.
- **`zai-glm-5-3`, `zai-glm-5-3-flash`, and `deepseek-v4-1-flash-1017` in the
  Mistral catalog,** each with a 1,048,576-token context window and a
  128,000-token output limit. Per MTok: GLM 5.3 costs $1.40 input, $0.14
  cached input, and $4.40 output; GLM 5.3 Flash $0.15, $0.03, and $0.50; and
  DeepSeek V4.1 Flash 1017, a preview model, $0.30, $0.007, and $1.20.
- **`claude-fable-5-2` in the model catalog,** with its 1M-token context
  window, 128K output limit, `low` to `max` effort ladder, task budgets, and
  prices of $8 input, $40 output, $0.20 cache read, $10 five-minute and $16
  one-hour cache write per MTok. Like Fable 5.1, it rejects temperature, an
  assistant prefill, and forced tool choice. The entry notes Anthropic's new
  prefix check: thinking blocks sent back after `system`, tools, or earlier
  messages change fail with a 400.
- **`gpt-6.1-terra` in the model catalog,** with its 1,050,000-token context
  window, 128,000-token output limit, `none` to `max` effort ladder, and
  prices of $1 input, $5 output, $0.05 cache read, and $1.25 cache write per
  MTok, doubled for input and cache and 1.5x for output above 272K input
  tokens.
- **`muse-ember-1.0` in the model catalog,** Meta's efficient execution
  model, with its 1,048,576-token context window, 524,288-token output limit,
  `minimal` to `max` effort ladder (default `max`), image, PDF, and tool
  support, and prices of $0.10 input, $0.50 output, and $0.004 cached input
  per MTok, tripled above 200K input tokens, plus $2.50 per 1,000 search
  queries.

### Changed

- **The catalog's default Mistral model is `mistral-large-4`,** in place of
  `mistral-medium-latest`, which points to the deprecated Mistral Medium 3.5.
  Mistral names Large 4 as Medium 3.5's replacement; it costs $0.70 input and
  $2.10 output per MTok. The `dashi` CLI lists it first for Mistral.
- **Decide v0.5.0 and Wonton v0.14.2.** Dashi's `decide/` packages and the
  `dashi` CLI build on the latest releases.
- **The catalog's default Google model is `gemini-4-hydrogen`,** which
  Google labels its default general-purpose model and the recommended
  upgrade from `gemini-3.8-flash`, the previous default. It costs twice as
  much per input and output token as `gemini-3.8-flash` does today and thinks at `high` by
  default. The `dashi` CLI features Carbon, Argon, Hydrogen, and
  `gemini-3.5-flash-lite` for Google.
- **`glm-5-2` and `zai-glm-5-2` are marked deprecated.** Mistral deprecated
  them on 2026-09-29 and scheduled retirement for 2026-10-31; they still
  answered on 2026-11-12. Use `zai-glm-5-3`, at the same price.
- **Mistral Large 4 is generally available in the catalog** (`mistral-large-4`
  and `mistral-large-4-0`, no longer preview) with a 1,048,576-token context
  window, up from 524,288, and the current prices of $0.70 input, $0.07 cached
  input, and $2.10 output per MTok, down from $1.36, $0.14, and $4.18.
- **`mistral-large-latest` now names Mistral Large 4,** as Mistral's models
  endpoint does, with Large 4's window and prices instead of Mistral Large 3's.
- **`mistral-large-2512` (Mistral Large 3) and `mistral-medium-3-5` and
  `mistral-medium-2604` (Mistral Medium 3.5) are marked deprecated.** Mistral
  deprecated them on 2026-10-31, retires them on 2027-04-30, and names Mistral
  Large 4 as the alternative. `mistral-medium-latest`, the Mistral default,
  still points to Medium 3.5 and stays current; its note records the date.
- **`catalog.Small("meta")` returns `muse-ember-1.0`.** Meta recommends Muse
  Ember for sub-agents, routing, and high-volume work; before, Meta had no
  small model.

### Fixed

- **Meta calls get a cost estimate again.** Meta now reports service tier
  `default` on pay-as-you-go responses, where it reported `auto` before, so
  `catalog.Cost` estimated nothing for any Muse model. The catalog now prices
  `default` for Meta at the model's standard rate.
